# 骰子（亡命之途）

> 来源：`亡命之途卡牌及骰子内容.xls` 工作表「骰子」
> 含两类骰子：普通骰子、强化骰子。各 6 个骰面，对应数值 1-6。

## 普通骰子

| 骰子数值    | 骰面名称 | 结算具体效果描述                                         |
| ------- | ---- | ------------------------------------------------ |
| 骰子数值为：1 | 空白   | 你躲避了丧尸攻击，无事发生。                                   |
| 骰子数值为：6 | 咬伤   | 你其中1个队员被丧尸咬中，你若能支付1个药剂便能救下他，否则将失去1位队员。           |
| 骰子数值为：3 | 击杀   | 击杀1个丧尸。                                          |
| 骰子数值为：4 | 击杀   | 击杀1个丧尸。                                          |
| 骰子数值为：2 | 伺机而动 | 你与丧尸陷入了缠斗。可以支付1个药剂临时提升战斗力击杀丧尸；若不支付药剂则视为成功躲避丧尸攻击。 |
| 骰子数值为：5 | 额外击杀 | 你击杀了1个丧尸，并且可支付1个药剂用于额外击杀1个丧尸。                    |

## 强化骰子

| 骰子数值    | 骰面名称 | 结算具体效果描述                                         |
| ------- | ---- | ------------------------------------------------ |
| 骰子数值为：1 | 咬伤   | 你其中1个队员被丧尸咬中，你若能支付1个药剂便能救下他，否则将失去1位队员。           |
| 骰子数值为：6 | 死亡   | 你其中1个队员被丧尸咬死，失去1位队员。                             |
| 骰子数值为：3 | 击杀   | 击杀1个丧尸。                                          |
| 骰子数值为：4 | 击杀   | 击杀1个丧尸。                                          |
| 骰子数值为：2 | 伺机而动 | 你与丧尸陷入了缠斗。可以支付1个药剂临时提升战斗力击杀丧尸；若不支付药剂则视为成功躲避丧尸攻击。 |
| 骰子数值为：5 | 额外击杀 | 你击杀了1个丧尸，并且可支付1个药剂用于额外击杀1个丧尸。                    |
