# 玩家使用指南（亡命之途 · 文字版）

> 适用版本：v0.6.1（Mac 终端单人 SOLO）。本指南只讲"怎么玩"，规则实现口径见《开发任务规划》。

## 1. 这是什么

一款纯文字的末世公路生存游戏：你带领一支幸存者小队，沿三阶段公路前进，每轮在三条路线中择一推进，沿途拾荒、处理突发事件、与丧尸战斗。走完 8 轮即抵达终点，按卡牌分、剩余人与物资结算总分与评级；中途全队覆没则旅程失败。

## 2. 安装与启动（macOS）

```bash
cd z_road
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt   # 首次：装 rich 与 pytest
pip install -e ".[desktop]"           # 注册 zroad 命令
zroad                                 # 启动；也可用 python -m zroad
```

## 3. 主菜单

| 选项         | 说明                                                             |
| ---------- | -------------------------------------------------------------- |
| `n` 新游戏    | 可输入整数随机种子（同种子+同操作可复现整局），直接回车则随机                                |
| `c` 继续自动存档 | 读取最近一轮末的自动存档（无存档时不可选）                                          |
| `l` 读取存档   | 进入读档列表：`a` 自动档、`1/2/3` 手动槽、`b` 返回；显示轮次/人数/已赢卡牌数/保存时间；已结算的局不可继续 |
| `q` 退出     | 回到命令行                                                          |

## 4. 一局的流程

### 4.1 开局 Setup（自动完成）

- 三阶段牌池 I/II/III 分别为 16/22/22 张，每阶段随机剔除 4 张，实际登场 12/18/18 张；
- 阶段 I 进行 2 轮、阶段 II/III 各 3 轮，共 8 轮；
- 初始：幸存者 5 人（1 主角 + 4 跟随者），弹药/汽油/药剂各 4。

### 4.2 规划阶段：三选一

每轮系统把 6 张牌组成三条路径（每条 2 张），面朝上的牌只显示"事件：有/无"（不显示编号），面朝下显示"？？（背面）"：

| 路径  | 明暗   | 选前效果                          |
| --- | ---- | ----------------------------- |
| 路径一 | 两张全暗 | **领取 2 个任意资源**（自己分配给弹药/汽油/药剂） |
| 路径二 | 左明右暗 | 无奖惩                           |
| 路径三 | 两张全明 | **支付 2 个任意资源**（总资源不足时不可选）     |

- 按 `1/2/3` 选择路径；涉及任意资源时按提示输入每种资源的数量，最后一种自动补齐；
- **查看明牌详情**：输入 `2L`（路径 2 左卡）、`2R`（路径 2 右卡）、`3L`、`3R`（大小写均可），可看到该卡的**拾荒资源、事件描述、战斗（丧尸数/屍群等级）、得分**，看完回到选路；背面卡会提示看不到；
- 顶部状态面板随时显示当前累计"得分：N"（已赢卡牌分 + 事件额外分；套装分终局才结算）。

### 4.3 遭遇阶段：逐张结算两张卡

每张卡按三步进行，界面依次显示：

1. **拾荒**：按卡面自动获得资源（绿字）；
2. **事件**：黑字立即事件自动结算，部分需要你抉择：
   - 损失哪种资源（三选一）；
   - 是否支付汽油（每少付 1 损失 1 人，默认建议足额）；
   - 是否花弹药留住"狂热者"等；
3. **战斗**：有丧尸则进入战斗界面（见下）；无丧尸直接赢得卡牌。

### 4.4 战斗操作

战斗面板显示剩余丧尸数、屍群等级（对应强化骰数量）与本场限制（禁药剂/禁逃跑/远程咬伤增敌）。近战前可选：

| 选项       | 规则                                    |
| -------- | ------------------------------------- |
| `r` 远程攻击 | 每场限一次；每个弹药掷 2 颗普通骰，只有"击杀/额外击杀"面各杀 1 只 |
| `f` 逃跑   | 支付 2 汽油，弃掉本张卡（不得分），脱离战斗               |
| `m` 近战   | 每名幸存者掷 1 颗骰，屍群按等级换等量强化骰（持校车则全部降级为普通骰） |

近战掷骰后列出每颗骰的结果。出现药剂机会时，按提示**输入要用药剂的骰号**（逗号分隔，直接回车表示不用）：

- 咬伤：付 1 药剂救下队友，否则 -1 人（强化骰的"死亡"面无法救援）；
- 额外击杀：付 1 药剂再多杀 1 只；
- 伺机而动：付 1 药剂反杀 1 只，否则该骰躲避、不生效。

丧尸清零即胜利并赢得卡牌；幸存者归零则全队覆没、游戏结束。

### 4.5 轮末

- 系统**自动存档**；
- `c` 进入下一轮，`s` 另存到手动槽（再按 `1/2/3` 选槽，覆盖前会确认），`q` 存好并退回主菜单。

### 4.6 终局结算

走完第 8 轮（或中途覆没）后显示：

- **卡牌得分**：赢得卡牌的卡面分合计；
- **事件额外分**：如地图道具加成分；
- **套装分**：每凑齐 1 名幸存者 + 1 汽油 + 1 弹药 + 1 药剂为一套，每套 +1 分（套数取四者最小值）；
- **总分**与**评级**：

| 总分    | 评级     |
| ----- | ------ |
| 0–5   | 神父加百列  |
| 6–10  | 还好     |
| 11–15 | 不错     |
| 16–18 | 非常好    |
| 19–21 | 叫我达瑞   |
| 22+   | 幸运儿或天才 |

同时给出局后统计（战斗场次、击杀、损失、逃跑）。

## 5. 存档说明

- 存档为 JSON 文件，默认在仓库根 `saves/`：`auto.json`（自动）与 `manual_1/2/3.json`；
- 设置环境变量 `ZROAD_SAVE_DIR` 可更换存档目录；
- 存档包含随机数状态，读档后摸牌与掷骰序列与退出前完全一致。

## 6. 操作小贴士

- 所有操作都是按键 + 回车，**每个菜单的按键都直接写在选项文字里**（如"新游戏（n）""远程攻击（r）"），照括号里的键按即可；确认用 `y/n`，纯推进处直接回车；
- 选路拿不准时，先用 `2L/3R` 等命令把明牌的事件、拾荒和得分看清楚再决定，路径一/三还要算上 2 个资源的奖惩；
- 路径三"不可选"表示当前三种资源总数不足 2；
- 药剂紧张时，优先用在"咬伤"上保人，"额外击杀/伺机而动"视局势取舍；
- 想研究某一局：开局输入固定种子，之后每一步都可复现。
